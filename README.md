# Number Guessing Game in C

A simple number guessing game written in the C programming language.

## About the Project

In this game, the computer generates a random number between 1 and 100.
The player tries to guess the number.

After each guess, the program gives a hint:
- If the guess is too high, it asks the player to enter a lower number.
- If the guess is too low, it asks the player to enter a higher number.
- When the correct number is guessed, the game displays the result.

The game also keeps track of the number of guesses and the player's score.

## Features

- Random number generation
- Higher/lower hints
- Number of guesses tracking
- Score system
- Option to play the game again

## Technologies Used

- C
- Standard C libraries

## How to Run

1. Download or clone this repository.
2. Open `main.c` in a C compiler or IDE.
3. Compile and run the program.
